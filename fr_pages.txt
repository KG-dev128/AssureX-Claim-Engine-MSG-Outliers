1.7 Non-Functional Requirements
There are several non-functional requirements that should be fulfilled by the application
which are as follows:
1. Performance: The application should process uploaded claim details and
generate predictions from both models within five seconds under normal
operating conditions.
2. Scalable: The application should be able to store and manage at least
10,000 warranty claims and support multiple manufacturers, service
centers, products, and concurrent users without significant performance
degradation.
3. Usable: The application should provide an intuitive and user-friendly Web
interface for customers, service-center employees, reviewers, and
administrators.
4. Accuracy: The Python classification model and Google Teachable Machine
model should achieve an overall accuracy of at least 85% on unseen test
claims and should reliably identify claims requiring manual review.
